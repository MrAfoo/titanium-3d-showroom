# Titanium 3D Showroom

Next-generation hardware scrollytelling showcase featuring the **Galaxy S26 Ultra**, **Tab S11 Ultra**, **Watch Ultra**, and **Buds Pro**.

Built with HTML5 Canvas 2D, GSAP 3 ScrollTrigger, 60FPS lerp rendering engine, Web Audio haptics, and a glassmorphic UI system.

## Features

- **Quad-Ecosystem Scrollytelling:** Interactive 3D hardware deconstruction stages.
- **60FPS Lerp Engine:** Ultra-smooth frame-sequence rendering.
- **Interactive Telemetry Hotspots:** Dynamic hardware breakdown cards with glassmorphic design.
- **Web Audio Haptics:** Procedural mechanical audio feedback.
- **360° Turntable Drag:** Drag-to-rotate interactive product inspection.
- **Responsive Floating Island Navbar:** Seamless navigation across mobile, tablet, and desktop viewports.

## Tech Stack

- **HTML5** & **Vanilla CSS3** (Custom Tokens & Glassmorphism)
- **JavaScript (ES6+)**
- **GSAP 3** (ScrollTrigger & ScrollToPlugin)
